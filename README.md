# Smart Household Account Book

Java Swing으로 만든 개인용 가계부입니다. 소프트웨어시스템설계 CP4 베타 버전으로, 거래 내역과 예산을 관리하고 소비를 줄였을 때의 예상 절감액을 확인할 수 있습니다.

구매를 참은 내역은 ‘꾹참기’에 기록합니다. 이 금액은 가상 절약액으로 따로 보관하고, 사용자가 실제로 저축했다고 확인한 경우에만 목표의 실제 저축액에 한 번 반영합니다.

## 주요 기능

- 수입·지출 등록, 수정, 삭제와 조건 검색
- 월별 예산 설정, 잔액과 예상 지출 확인
- 카테고리별 소비 분석과 절감액 계산
- 저축 목표와 달성률 관리
- 꾹참기 기록, 가상 영수증, 실제 저축 반영

## 빌드와 실행

Windows와 PowerShell을 기준으로 작성했습니다. 소스 빌드에는 JDK 17 이상이 필요하며 외부 라이브러리는 사용하지 않습니다. 실제 검사는 JDK 25.0.1에서 했고, 컴파일 대상은 Java 17입니다. Java 17 런타임에서의 실행은 별도로 확인하지 않았습니다.

저장소를 내려받고 프로젝트 폴더에서 다음 명령을 실행합니다. `-JdkHome`은 PC에 설치된 JDK 경로로 바꿔 주세요.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -JdkHome 'C:/Program Files/Java/jdk-25'
```

빌드 스크립트는 컴파일, 실행 JAR 생성, 기능 검사, Javadoc 생성을 진행합니다. 현재 60개 확인 항목을 통과했습니다.

빌드가 끝나면 일반 실행은 `run.bat`, 예시 데이터 실행은 `demo.bat`을 사용합니다. 명령으로도 실행할 수 있습니다.

```powershell
java '-Dfile.encoding=UTF-8' -jar .\dist\ssd_ip_cp4_2026f_223247_app.jar
java '-Dfile.encoding=UTF-8' -jar .\dist\ssd_ip_cp4_2026f_223247_app.jar --demo
```

JAR와 생성된 API 문서는 Git에 포함하지 않으므로 처음에는 빌드가 필요합니다. 생성한 JAR만 실행할 때는 JDK 대신 Java 런타임을 사용할 수 있습니다.

## 데모에서 확인할 내용

데모 기준일은 계산 결과를 비교하기 위해 2026년 10월 15일로 고정했습니다. 일반 실행에서는 PC의 현재 날짜를 사용합니다.

| 확인할 기능 | 예시 결과 |
|---|---|
| 월별 현황 | 예산 500,000원, 지출 300,000원, 사용률 60% |
| 월말 예상 | 예상 지출 620,000원, 예상 초과액 120,000원 |
| 식비 20% 절감 | 월간 30,000원, 연간 360,000원 |
| 꾹참기 30,000원 실제 반영 | 목표 저축액 500,000원 → 530,000원, 달성률 25% → 26.5% |

데모는 실행할 때마다 별도의 임시 폴더를 사용합니다. 일반 실행에서 저장한 데이터에는 영향을 주지 않습니다.

## 데이터 저장

일반 실행의 저장 파일은 사용자 홈의 `.smart-household/ledger.dat`이며 화면 하단에서도 위치를 확인할 수 있습니다. 종료 후 다시 실행하면 저장한 내용을 불러옵니다.

다른 경로를 사용하려면 다음과 같이 지정합니다.

```powershell
java '-Dfile.encoding=UTF-8' -jar .\dist\ssd_ip_cp4_2026f_223247_app.jar --data .\data\ledger.dat
```

데이터는 Java 직렬화 파일로 저장하며 암호화하지 않습니다. 직접 생성한 데이터 파일을 사용하세요. 저장할 때는 임시 파일에 먼저 기록하고 원본을 교체합니다. 파일이 손상되면 오류를 표시하며 자동으로 덮어쓰지 않습니다.

## 현재 제한

- 한 사람이 PC에서 사용하는 프로그램이며 은행 연동, 자동 이체, 로그인은 없습니다.
- 실제 저축 여부는 사용자가 확인합니다. 직접 저축 추가와 꾹참기 반영에 같은 돈을 입력했는지는 자동으로 구분하지 못합니다.
- 꾹참기는 기록 전액을 한 번만 반영할 수 있습니다. 부분 반영과 반영 취소는 지원하지 않습니다.
- 월말 지출은 단순 일평균으로 예상합니다. 현재 월의 누적 지출과 과거 전체 월 평균을 비교하므로 비교 기간에도 차이가 있습니다.
- 작은 데이터 기준으로 파일 작업을 화면과 같은 스레드에서 처리합니다. 데이터가 많으면 화면이 잠시 지연될 수 있으며, 표의 금액 정렬은 표시 문자열 기준입니다.
